# The Drowned Bell: full script

Every spoken line in the game, in the order of the script file (js/lines.js), grouped by chapter and location.
Each line: speaker, line id in brackets, then the text. Words in [square brackets] are performance directions for the voice actor; they are not shown on screen.
Lines marked † are not referenced by name in the story code: some are built from a pattern (random fail lines, numbered sequences), others may be unused.
